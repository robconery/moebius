# Code of Conduct

Moebius follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be welcoming, be kind, and assume good intent. Harassment, insults and personal attacks aren't welcome in issues, pull requests or anywhere else the project lives.

If someone's behavior is a problem, please contact the maintainers privately through the [Security tab's private reporting](https://github.com/robconery/moebius/security) or by messaging a maintainer on GitHub. Reports are kept confidential.
